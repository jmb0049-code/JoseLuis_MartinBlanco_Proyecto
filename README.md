# Mis Proyectos de JavaScript - Entrega Final

Este repositorio contiene los dos proyectos prácticos realizados para la asignatura, enfocados en el uso de bucles, manipulación del DOM y lógica de eventos.

## 📁 Estructura del Repositorio
* **Proyecto1/**: Tablero de ajedrez dinámico generado con bucles anidados.
* **Proyecto2/**: Juego  con lógica de saltos y detección de colisiones.

## 🚀 Tecnologías utilizadas
* HTML5
* CSS3 (Animaciones y Flexbox)
* JavaScript (DOM, Event Listeners, SetInterval)

## 🕹️ Cómo ejecutar
Basta con abrir el archivo `index.html` de cada carpeta en cualquier navegador moderno.
